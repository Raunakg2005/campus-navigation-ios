# Campus Navigation (SwiftUI + MapKit)

iOS Experiment 7 — Campus Navigation with nearby libraries.

**Name:** Raunak Kumar Gupta
**Roll No:** 16010123250

## Features
- Campus map with library annotations and user location
- Nearby libraries sorted by distance
- Library details (name, location, distance, books)
- Search by library or book name
- Walking directions with route on map

## Run
Requires Xcode 15+ / iOS 17+.

```bash
git clone https://github.com/Raunakg2005/campus-navigation-ios.git
cd campus-navigation-ios
open CampusNav.xcodeproj
```

In the simulator, set a location via **Features > Location > Apple** (the sample libraries are placed around it).
